Contracts that carry messages (controller ↔ driver ↔ unit)

These contracts are the actual "wire" between the parts. Each dispatch produces a fixed set of three files, all named by the dispatch id <node>.g<generation>.<unit>.r<round>. Because the name includes the generation and the round, no message file is ever overwritten. {{ cite('src-dispatch-id') }} {{ tag('sure') }}

In: packet

packets/coding.g2.worker.r1.md
rendered by the driver, pinned by sha256

In: rules

packets/coding.g2.worker.r1.rules.json
the node's selected rules

Out: result

results/coding.g2.worker.r1.md
written by the unit, digest recorded

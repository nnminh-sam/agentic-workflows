# delivery-drafts

**Goal:** the drafts the delivery adapter lists (`profile.delivery.drafts`), written to `drafts/<name>.md`.

Use the adapter's template for each one (commit message convention, PR body sections, tracker reply format
and language). Cite evidence files; never paste them. State what changed, why, how it was verified, and what
the reviewer should check. No process labels (node or gate ids) in any draft.

How one node hands work to the next

In one sentence: a node declares the tokens it requires and produces; the driver lets it run only when every required token has a producer whose record is done, and the actual content travels as files the producer wrote into the ticket directory.

Control: tokens

A token is an abstract name for "this kind of output exists and is approved", such as approved-plan. It is not a file. Several nodes may produce the same token: analysis comes from investigate on a bug and from requirement-analysis on a feature. That is how the two analysis branches merge into one implementation layer. {{ cite('src-graph-order') }}

The readiness rule is: for each required token, find the nodes in this ticket's trace that produce it. If there are some and none is done, the node is not ready. A token that no node in the trace produces is ignored. This is how a family token (for example the IF proof) blocks final-review only when the family is on. {{ cite('src-missing', 'src-feeds') }} {{ tag('sure') }}

Data: artifact files

Tokens say that a predecessor finished. What it found travels as files. coding reads plan.md, and code-review reads the diff plus plan.md. The packet names only the node's own output files and the ticket directory, so a unit finds its inputs by the naming convention in the node cards. {{ cite('src-dispatch-id', 'src-artifacts-expand') }} {{ tag('sure') }}

Review point: inputs are implicit. The token table above already maps each token to its producer's files, so an inputs list per node could be generated and rendered into the packet (R3 in review points).

Going back: invalidation

When an earlier output is wrong, invalidate --node X (or a needs-changes gate, or triage-review --reopen X) walks forward from X. It collects every later node whose requires overlaps the tokens produced so far. Those nodes become stale with generation + 1. Every other node keeps its record. If final-review is among them, the receipts are dropped. {{ cite('src-dependents', 'src-invalidate') }} {{ tag('sure') }}

Contracts that record a ticket's progress (state)

These are written only by the driver, during a ticket's life. state.json is the current view and the only thing the driver trusts. decisions.jsonl is the audit trail of how it got there. {{ cite('src-save', 'src-log') }} {{ tag('sure') }}

state.json
├─ schemaVersion · graphId · profilePath · createdAt
├─ context            → ticket-context (kind, families, surfaces, repositories[], reviewRound)
├─ nodes
│   └─ <node-id>      → node-record (status, generation, attempts, verdict, subject?, artifactDigests?)
│       └─ units[]    → unit-record (unit, generation, model, status, result, resultDigest, verdict…)
└─ receipts
    └─ <repo-id>      → receipt (head, subject, issuedAt, expiresAt)

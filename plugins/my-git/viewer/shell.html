git-guard rules

How decisions work. Every rule has a severity: deny blocks the command, ask asks you to confirm, warn lets it run with a warning, off disables the rule. The strictest finding wins.
Edit the JSON files in .claude/hooks/git-guard/contracts/, then refresh this page with: 
python .claude/hooks/git-guard/scripts/render_rules.py --open
Check a message by hand: python .claude/hooks/git-guard/scripts/check_message.py "feat(api): add retry"
